# Residual-Based Relative-Energy Adapter from a Finite Fourier Path to Leray--Hopf Navier--Stokes

**Status:** analytic derivation (`Dr`) plus finite residual algebra.  
**Date:** 2026-09-10.  
**Scope:** periodic incompressible Navier--Stokes; comparison with a smooth divergence-free finite Fourier path.  
**Non-claim:** no global regularity, singularity, uniqueness-for-all-weak-solutions, or Clay Millennium claim.

This note attacks the remaining bridge `PROP-EPSC-12`: how can a finite Fourier computation be connected to the **actual** continuum projected solution strongly enough to drive a terminal epsilon certificate?

The key is not to assume that a Galerkin trajectory equals `P_Ku`. Instead, treat the finite path as an approximate solution, compute its equation residual, and use the standard relative-energy inequality to bound its distance from any Leray--Hopf solution with the same data.

---

## 1. Approximate finite path and residual

Let `u` be a Leray--Hopf weak solution of

\[
\partial_tu+P[(u\cdot\nabla)u]-\nu\Delta u=Pf,
\qquad \nabla\cdot u=0,
\]

on the periodic three-torus.

Let `v` be a smooth divergence-free comparison path, for example a finite Fourier polynomial generated by a Galerkin computation or by a smooth interpolation of a numerical trajectory. Define its residual by

\[
\boxed{
r
:=
\partial_tv+P[(v\cdot\nabla)v]-\nu\Delta v-Pf.
}
\]

Thus `v` obeys the target equation exactly when `r=0`.

For an exact `K`-Galerkin semidiscrete path with unforced dynamics, the in-cube residual is zero by construction and the unresolved residual is

\[
r_K=(I-P_K)P[(v_K\cdot\nabla)v_K].
\]

Because `v_K` is supported in the `K` cube, this quadratic residual is supported in a finite `2K` cube and can be computed by finite ordered triads.

---

## 2. Relative-energy adapter theorem

Write

\[
w=u-v,
\qquad
y(t)=\|w(t)\|_2^2.
\]

Subtract the equations and test by `w`. Periodicity and incompressibility cancel the transport terms except for the deformation of `v`, giving the standard relative-energy inequality

\[
\frac12y(t)+\nu\int_0^t\|\nabla w\|_2^2ds
\le
\frac12y(0)
+
\int_0^t\|\nabla v\|_\infty y(s)ds
+
\int_0^t|\langle r,w\rangle|ds.
\]

Using

\[
|\langle r,w\rangle|
\le
\|r\|_{H^{-1}}\|\nabla w\|_2
\le
\frac{1}{2\nu}\|r\|_{H^{-1}}^2
+
\frac\nu2\|\nabla w\|_2^2,
\]

we obtain

\[
y(t)
\le
y(0)
+2\int_0^t\|\nabla v\|_\infty y(s)ds
+\frac1\nu\int_0^t\|r\|_{H^{-1}}^2ds.
\]

Define the finite/certified summary quantities

\[
A_T:=2\int_0^T\|\nabla v(t)\|_\infty dt,
\]

\[
B_T:=\int_0^T\|r(t)\|_{H^{-1}}^2dt,
\]

and let `e_0` be any certified upper bound on `||u_0-v(0)||_2`.

### Theorem 1 -- residual-based terminal adapter

\[
\boxed{
\sup_{0\le t\le T}\|u(t)-v(t)\|_2^2
\le
\exp(A_T)\left(e_0^2+\frac{B_T}{\nu}\right).
}
\]

### Proof

Apply Gronwall to the preceding scalar inequality. `square`

The right-hand side depends only on finite/certified summaries of the comparison path and residual.

## 3. Direct terminal Fourier-tail certificate

Suppose the terminal comparison state is supported in the retained cube:

\[
v(T)=P_Kv(T).
\]

Then

\[
(I-P_K)u(T)
=
(I-P_K)(u(T)-v(T)),
\]

hence

\[
\boxed{
\|(I-P_K)u(T)\|_2
\le
\beta_K^{RE}(T)
:=
\exp(A_T/2)
\left(e_0^2+\frac{B_T}{\nu}\right)^{1/2}.
}
\]

This is the important step: a finite trajectory with a certified residual can yield a **prescribed terminal full Fourier-tail certificate** without assuming a pointwise `H^s` bound for the unknown Leray solution.

The certificate may be numerically loose because of the exponential factor. That affects usefulness, not validity. If `beta_K^{RE} <= epsilon`, the EPSC gate has an analytic tail bound for the declared terminal `L2` target.

## 4. Integrated gradient-error bound

The absorbed relative-energy inequality also gives a conservative bound on the integrated gradient error.

Let

\[
E_T^2
:=
\exp(A_T)\left(e_0^2+\frac{B_T}{\nu}\right).
\]

Since `y(t)<=E_T^2`, integration yields

\[
\boxed{
\int_0^T\|\nabla(u-v)\|_2^2dt
\le
\frac1\nu
\left(
e_0^2+A_TE_T^2+\frac{B_T}{\nu}
\right).
}
\]

This converts the adapter into the directional retained-energy tape required by the separate terminal energy-budget certificate.

If

\[
Z_T
:=
\left[
\frac1\nu
\left(e_0^2+A_TE_T^2+\frac{B_T}{\nu}\right)
\right]^{1/2},
\]

then for a `K`-supported `v`,

\[
\|P_Ku(T)\|_2
\ge
\max\{0,\|v(T)\|_2-E_T\},
\]

and

\[
\|\nabla P_Ku\|_{L^2_tL^2_x}
\ge
\max\{0,
\|\nabla v\|_{L^2_tL^2_x}-Z_T
\}.
\]

The latter produces a certified lower bound on retained viscous dissipation after squaring and multiplying by `nu`.

Thus the relative-energy route and the energy-budget route are complementary rather than competing.

## 5. Finite computability of the residual summaries

For a finite Fourier state

\[
v(x,t)=\sum_{k\in\mathcal K_K}\widehat v_k(t)e^{ik\cdot x},
\]

a conservative pointwise coefficient bound is

\[
\boxed{
\|\nabla v(t)\|_\infty
\le
\sum_{k\in\mathcal K_K}|k|_2|\widehat v_k(t)|_2.
}
\]

For an exact unforced Galerkin path, each unresolved residual coefficient is a finite triad sum

\[
\widehat r_q
=
P_q
\left[
i\sum_{p+s=q}(s\cdot\widehat v_p)\widehat v_s
\right],
\qquad
\|q\|_\infty>K,
\]

and no output beyond the finite `2K` cube can occur.

With the homogeneous periodic `H^{-1}` norm,

\[
\boxed{
\|r(t)\|_{H^{-1}}^2
=
\sum_{q\ne0}
\frac{|\widehat r_q(t)|^2}{|q|_2^2}.
}
\]

Therefore the **integrands** entering `A_T` and `B_T` are finite functions of finite Fourier records.

The remaining numerical-certification obligation is to upper-bound their time integrals rigorously over the entire continuous-time interval, rather than merely sampling them at RK4 nodes.

## 6. Exact Galerkin versus RK4 path

Two cases must not be conflated.

### Exact semidiscrete Galerkin trajectory

If `v_K(t)` is the exact solution of the finite Galerkin ODE, then its residual is exactly the unresolved nonlinear Fourier tail above. A validated ODE integrator or interval enclosure can certify `A_T` and `B_T`.

### Current floating-point RK4 trajectory

The repository currently stores discrete RK4 states. Those node values do **not** by themselves define an exact continuous path satisfying the Galerkin ODE. To use Theorem 1, construct a continuous interpolation `v_h(t)` and include its full residual

\[
r_h
=
\partial_tv_h+P[(v_h\cdot\nabla)v_h]-\nu\Delta v_h-Pf.
\]

This residual automatically includes both spectral truncation error and time-discretization/interpolation error.

Therefore the remaining engineering task is precise:

> build a validated continuous-time reconstruction of the RK4 tape and certified interval upper bounds for `A_T` and `B_T`.

That is narrower than the original open-ended “finite-to-continuum bridge.”

# Navier--Stokes Readout Observability, Jet Order, and the Compression Gate

## Status

This note continues the finite Galerkin program after `NS_MINIMAL_DYNAMIC_READOUT.md`.
It answers two different questions separately:

1. can an exact finite readout order be found in any genuine Navier--Stokes Galerkin case?
2. is the minimal all-future readout state actually much smaller than the finite 3D state?

The answers are:

\[
\boxed{R^\star=1}
\]

for one exact interacting triad subcase, but for the first full three-dimensional cube
truncation tested here,

\[
\boxed{
\dim \mathcal Q_{\min,\mathrm{loc}}^{NS}=49,
\qquad
d_M=52.
}
\]

Thus the all-future exact shell reader removes only the three continuous spatial-translation
gauge directions at a generic point of this truncation.  It is therefore **not** a strong
state compression.

This is a finite-Galerkin result.  It is not a continuum regularity result and not a claim
about all resolutions.

# 2. An exact interacting triad with \(R^\star=1\)

Consider the 2D vorticity invariant subspace of the 3D periodic Navier--Stokes Galerkin
system generated by

\[
a=(1,0,0),
\qquad
b=(1,1,0),
\qquad
c=(-2,-1,0),
\qquad
a+b+c=0.
\tag{2.1}
\]

The squared wavenumbers are

\[
|a|^2=1,
\qquad
|b|^2=2,
\qquad
|c|^2=5.
\tag{2.2}
\]

Let \(A,B,C\in\mathbb C\) be the three independent vorticity amplitudes; the negative
modes are their complex conjugates.  Direct Fourier convolution gives

\[
\boxed{
\dot A
=
\frac{3}{10}\overline B\,\overline C
-\nu A,
}
\tag{2.3}
\]

\[
\boxed{
\dot B
=
-\frac45\overline C\,\overline A
-2\nu B,
}
\tag{2.4}
\]

\[
\boxed{
\dot C
=
\frac12\overline A\,\overline B
-5\nu C.
}
\tag{2.5}
\]

The nonlinear coefficients satisfy exactly

\[
\frac{3}{10}-\frac45+\frac12=0
\tag{2.6}
\]

and

\[
\frac{3/10}{1}
+
\frac{-4/5}{2}
+
\frac{1/2}{5}
=0,
\tag{2.7}
\]

which are the triad enstrophy- and kinetic-energy transfer cancellations.

Define

\[
x=|A|^2,
\qquad
y=|B|^2,
\qquad
z=|C|^2,
\qquad
r=\Re(ABC).
\tag{2.8}
\]

Then (2.3)--(2.5) imply the closed real system

\[
\boxed{
\dot x
=
\frac35 r-2\nu x,
}
\tag{2.9}
\]

\[
\boxed{
\dot y
=
-\frac85 r-4\nu y,
}
\tag{2.10}
\]

\[
\boxed{
\dot z
=
r-10\nu z,
}
\tag{2.11}
\]

\[
\boxed{
\dot r
=
\frac{3}{10}yz
-\frac45xz
+\frac12xy
-8\nu r.
}
\tag{2.12}
\]

The discarded companion

\[
s=\Im(ABC)
\tag{2.13}
\]

obeys

\[
\dot s=-8\nu s
\tag{2.14}
\]

and never appears in (2.9)--(2.12).  Therefore it is not required by the shell-energy
future.

The velocity-shell readout is, up to fixed known weights,

\[
J_0
=
I
=
\left(x,\frac{y}{2},\frac{z}{5}\right).
\tag{2.15}
\]

Hence \(J_0\) determines \((x,y,z)\).  From the first derivative,

\[
\boxed{
r
=
\frac{5}{3}\left(\dot x+2\nu x\right),
}
\tag{2.16}
\]

so \((J_0,J_1)\) determines \((x,y,z,r)\), and (2.9)--(2.12) determine every future
shell readout.

But \(J_0\) alone is insufficient: for example

\[
(A,B,C)=(1,1,1)
\tag{2.17}
\]

and

\[
(A,B,C)=(i,1,1)
\tag{2.18}
\]

have the same \((x,y,z)\) and different \(r\), hence different \(J_1\).

Therefore, for this exact Galerkin triad,

\[
\boxed{R^\star_{\mathrm{triad}}=1.}
\tag{2.19}
\]

The full real state has dimension six, while the exact shell-future quotient has generic
dimension four:

\[
\boxed{
6\longrightarrow4.
}
\tag{2.20}
\]

This is genuine exact reduction, but dimension reduction alone does not certify a speed-up.

\tag{3.2}

The exact \(|k|^2\)-shells are

\[
q\in\{1,2,3\},
\tag{3.3}

\dot x=F_M(x)=A_\nu x+B_M(x,x).

# 4. Why each new shell derivative contributes at most two new directions

The exact retained equation is

\[
J_1+L_\nu J_0=\eta^{NS}.
\tag{4.1}
\]

For the unforced incompressible Galerkin system, nonlinear transfer is conservative:

\[
\mathbf 1^T\eta^{NS}=0.
\tag{4.2}
\]

Differentiate repeatedly.  Since \(L_\nu\) is fixed,

\[
\boxed{
\mathbf1^T
\left(
J_{r+1}+L_\nu J_r
\right)
=0,
\qquad r\ge0.
}
\tag{4.3}
\]

Thus once \(J_r\) is known, every new three-component vector \(J_{r+1}\) contains at most
two new independent scalar distinctions.

Consequently

\[
\boxed{
\operatorname{rank}D(J_0,\ldots,J_R)
\le
3+2R.
}
\tag{4.4}
\]

There is also an independent geometric upper bound.  Spatial translations act by

\[
\widehat u_k\mapsto e^{ik\cdot a}\widehat u_k,
\qquad a\in\mathbb T^3,
\tag{4.5}
\]

and leave the complete future shell trajectory invariant.  At a generic state the
translation orbit is three-dimensional.  Therefore

\[
\boxed{
\operatorname{rank}Dq_{\min}
\le
52-3=49.
}
\tag{4.6}
\]

Combining the two upper bounds,

\[
\operatorname{rank}D(J_0,\ldots,J_R)
\le
\min(3+2R,49).
\tag{4.7}
\]

\boxed{

\tag{5.10}

A global equality

\[

\tag{5.11}

# 6. Raw jet redundancy is not state compression

At \(R=23\), the raw shell jet contains

\[
3(23+1)=72
\tag{6.1}
\]

scalar coordinates, but its generic differential rank is only

\[
49.
\tag{6.2}
\]

Thus there are at least

\[
72-49=23
\tag{6.3}
\]

coordinate redundancies in that representation.

However, the comparison relevant to acceleration is not 49 versus 72.  It is 49 versus
the original finite state dimension 52:

\[
\boxed{
\frac{49}{52}
=0.942307\ldots
}
\tag{6.4}
\]

Therefore

\[
\boxed{
\dim\mathcal Q_{\min,\mathrm{loc}}^{NS}
\not\ll d_M
}
\tag{6.5}
\]

for this first full 3D truncation.

The exact all-future shell quotient is mathematically valid but fails the intended strong
compression test here.

# 7. A scalar task does not automatically stay small over all future time

Let the task reader be total retained kinetic energy

\[
E=\mathbf1^T I.
\tag{7.1}
\]

The same exact modular calculation gives

\[
\boxed{
\operatorname{rank}D(E,\dot E,\ldots,E^{(R)})
=
\min(R+1,49)
}
\tag{7.2}
\]

for the checked range \(0\le R\le50\).

The first order reaching the generic local maximum 49 is

\[
\boxed{R=48.}
\tag{7.3}
\]

Thus even a one-scalar reader can, through its complete future evolution, recover almost
all generic local state distinctions modulo translation.

This is a direct warning against the inference

\[
\text{small output dimension}
\Longrightarrow
\text{small all-future sufficient state}.
\tag{7.4}
\]

It is false in this tested finite NS system.

# 8. Cost gate: HOLD

Finite Readout Acceleration uses measured costs, not state dimension alone.  Its exact
engineering criterion requires the cost of the expensive path and the cost of the quotient
path to be separately measured before a speed-up is reported.

Here we do not yet possess an independently executable 49-state propagator for
\(\mathcal Q_{\min}^{NS}\).  Evaluating the current jet from the full Fourier state still
requires the full Galerkin dynamics.

Therefore

\[
\boxed{
C(\mathcal Q_{\min}^{NS})
<
C(NS_{3D})
}
\tag{8.1}
\]

is currently

\[
\boxed{\text{HOLD}.}
\tag{8.2}
\]

Moreover, the dimensional result

\[
49/52\approx0.9423
\tag{8.3}
\]

shows that **all-future exact shell reduction is not the promising acceleration lever in
this truncation**.

This does not prove that a 49-variable implementation could never be faster; it proves that
the desired large state-collapse argument is unavailable here.
